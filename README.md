# Amazon-Prime-EDA
Exploratory Data Analysis of Amazon Prime Movies and TV shows using Python

# Amazon Prime Movies & TV Shows EDA
## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Amazon Prime
Movies and TV Shows dataset to understand content trends, ratings, genres,
popularity, production countries, actors, and directors.

## Business Objective
The objective of this project is to generate useful insights that can support
content planning, content acquisition, audience targeting, recommendations,
and promotional strategies.

## Dataset
The project uses two datasets:
- `titles.csv` - Contains information about movies and TV shows.
- `credits.csv` - Contains information about actors and directors.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Analysis Performed
The project includes:
- Data understanding and inspection
- Missing value analysis
- Duplicate handling
- Data cleaning and wrangling
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Data visualization
- Business insights

## Key Insights
- Movies make up the majority of titles in the dataset.
- TV Shows generally have higher IMDb ratings than Movies.
- Drama, Comedy, and Thriller are among the most represented genres.
- The United States contributes the largest number of titles, followed by
  India and the United Kingdom.
- Most IMDb-rated titles fall into the average rating category.
- IMDb Score and TMDB Score show a positive relationship.
- The dataset contains missing information, particularly for age certification
  and some rating-related variables.
